# U-Words

U-Words 是一个个人向、轻量的桌面口述工具。它把本地 Whisper / 千问云端语音识别、可选的大模型渲染和系统光标插入组合成一条短链路。

它不包含网页搜索、问答、账号体系、云端历史或订阅计费。

## 当前实现（0.6.7）

- 设置可选择切换或按住录音，默认切换；全局快捷键按住模式松开触发键完成，重复按下去重，取消后等待松开，启动期间松开不会遗留录音。口述和选区编辑均支持，页面按钮仍为点击切换。
- 快捷键先注册新增绑定，再移除旧绑定；冲突回滚新增绑定，旧快捷键与设置不被直接覆盖。修改任务串行执行，录音/处理时不允许更改录音方式或快捷键。若系统回滚本身失败仍需重试/重启，不保证系统操作绝对成功。
- 浮窗及口述工作台结果区域显示阶段驱动的平滑进度条，未完成时停在接近终点，不宣称真实百分比；结果返回立即显示/尝试交付，不为动画延迟，失败与取消不伪装完成。第三方输入框不插入占位文本。
- 音量显示按约 60 fps 的动画帧更新，采用展示用非线性增益、噪声门限及快速上升/平缓下降，不改变 ASR 音频样本；浏览器后台节流和原生 IPC 调度可能影响实际帧率，不把理论频率当测量结果。
- 同一录音内相邻句先判断补充、转折、条件等关系，有证据才衔接，独立要求不强合并、不添加因果；跨次参考默认关闭。开启“连续口述参考上一段”后，仅智能口述在同一可识别控件、30 秒内提供上一段尾部最多 400 个字符，随本次文字发送所配置模型，不读取外部正文、不重复输出上一段、不改写已经插入的内容。焦点元数据指纹是尽力匹配，不证明控件内容或文档从未变化，无法识别时不使用；取消、失败、明确换话题、超时和关闭开关会切断参考，翻译/选区编辑/只转写不携带参考。

- 复制结果卡片按当前鼠标所在屏幕定位；录音胶囊展开时保留录音所在屏幕，水平按整块屏幕居中，卡片底部距工作区底边 48 个逻辑像素，避免覆盖 Dock/任务栏。录音胶囊保留 24 个逻辑像素间距；坐标按缩放比例转换并限制在工作区内。
- 最终交付正文默认不加结尾句号，内部标点保留；提示词约束叠加保守的输出清理，保留代码、路径、URL、版本号、缩写、引用、问号、感叹号和省略号。原始 ASR 与裁决稿不被改写；含技术点号的歧义末尾宁可保留，不做全局替换。
- 三步首次进入旅程、场景词包、输入法/Typeless 导入、单词纠错学习及 SQLite 迁移目前是设计稿，尚未接入运行程序；现有按应用匹配风格的逻辑仍在，不能将设计稿视为已经生效。

- 默认智能口述强化自然成稿和技术保真：不凭常识新增方案、不混淆异步/并发/并行及构建/安装/验证状态，保留条件、问题、备选和不确定性；拒绝采用明确截断或异常结束的模型响应。提示词并非语义正确性证明，仍需真实样本评测。
- 可主动打开“检查方案”，确认正文和服务商后额外请求一次模型。整理正文、带原文依据的问题、标明采用条件的新增建议分区展示；建议不会自动应用，原历史不覆盖，整理正文确认后进入复制预览，不自动发往当前焦点。
- 未检测到可编辑光标、辅助功能未授权、自动插入关闭或插入失败时，浮窗展开为 340×220 的黑白复制卡片，保留完整可滚动文本；复制无需辅助功能，Esc/关闭只收起预览。正常录音仍使用小胶囊。
- 插入前检查可编辑目标和录音开始时的目标应用 PID，并在发送粘贴前再次检查；不能保证所有自定义编辑器可检测，也不把发送快捷键视为已验证文字上屏。
- 口述工作台移除右上角重复的编辑选区入口，录音区域的两个操作按钮统一为 36px 高、相同边距和图标尺寸。
- 识别语言按千问3-ASR-Flash官方参数提供 27 个语言代码及自动多语混说。本地 Whisper 同步传递相应语言，菲律宾语映射为 Tagalog；内置 tiny/base/small 无独立粤语 token，按中文识别并记录提示。此列表是识别语言，翻译目标仍为中文/英文。
- 历史编辑时保留首次生成的正文，便于原始转写/模型输出/用户修改对照；旧记录无法恢复此前未保存的首次输出。未新增对其他应用编辑内容的持续读取。
- 输入法词库接入目前只完成官方资料调研，未自动读取或导入其他输入法数据；现有通用 CSV/TXT 导入保留。

- 智能口述整理明确支持删除无意义填充、口吃和重复启动片段、轻度语序修复、明确改口与语义分段，并允许普通风格输出对应原文的编号列表。保留有意义的前置表达、强调、否定、范围、条件、和/或及不确定性；个人词典不强制替换，不回答正文中的问题、不添加事实。规则不等同于模型效果保证，尚未进行真实云端模型评测。
- 整理规则独立保存于 `src-tauri/src/prompts/dictation.txt`，不内置个人录音或 Typeless 历史。翻译与选区编辑仍有独立提示词；选区编辑数据通过 JSON 用户消息传递，不混入系统指令。只转写模式仍不调用渲染模型。默认单模型口述不增加 API 调用，现有多候选裁决行为不变。

- 移除静音自动结束采集逻辑与设置，旧 `vadEnabled` / `autoStopSeconds` 配置忽略，不会复活此行为。长停顿需用户手动完成或取消；云端单次音频长度和大小限制仍有效。

- macOS 加固运行时签名增加 `com.apple.security.device.audio-input`，修复打包遗漏导致的录音拒绝；此声明不代替用户麦克风授权。增加打包配置回归测试，发布后仍需检查实际签名。

- 浮窗错误状态使用感叹号，不再出现“错误 × + 关闭 ×”两把叉；各状态只有一个取消 / 关闭叉。
- 浮窗改为约 164×40 的中性灰胶囊，宿主窗口 166×42，处理中取消固定左侧；统一 SVG 图标，去掉彩色描边与光晕。
- 侧栏口述 / 编辑按钮的快捷键单独一行，避免按钮标题被挤断。确认弹窗的取消按钮只显示文字，不再与右上角叉重复。
- 开发模式 `/?overlayPreview` 可无录音、无 API 调用检查五种浮窗状态与深浅主题；不作为正式应用路由发布。

- 新增千问云端 ASR：固定 `qwen3-asr-flash`，Rust 直接将单声道 16 kHz PCM WAV 作为 Base64 提交至 OpenAI 兼容接口，无 Python、OSS 或自建服务端。
- 北京 / 新加坡接口已预置，默认北京。Token 按地域独立保存在系统凭据库；保存后启用云端识别，不发测试音频，不等同于已验证账户权限。
- 可选择复用同一百炼 Token，以 `qwen-plus` 非思考模式整理和翻译。原 DeepSeek / 智谱配置、Key 保留，关闭复用即可恢复。识别和整理分别计费。
- 云端的网络、超时、429、5xx 错误可回退本地 Whisper；401 / 403 等配置错误明确提示，不静默回退、不自动重复提交云端录音。音频大小超限提示分段或切换本地。
- 原始云端转写与最终整理结果仍分开保存，统计与历史留存在插入之后异步处理；云端接口未提供的置信度不会伪造。
- 配置持久化经过串行队列，避免并行写入覆盖新设置或争用临时文件。

- Tauri 2 + React + TypeScript，桌面壳体小，核心处理在 Rust 主进程。
- 本地 ASR 使用 whisper.cpp / whisper-rs，支持 tiny、base、small 的 Q5 模型档位。
- 默认使用随应用内置的 Whisper Small Q5（约 181 MiB / 190 MB），不需要首次联网下载；tiny、base 仍可在设置中按需下载和切换。
- 识别方式默认是单模型快速模式；可选“高精度”模式按录音时长运行已安装的 tiny/base/small 模型，保留各模型候选与主模型原文。智能渲染和翻译中的不同候选会交给用户配置的大模型保守裁决，再进行标点、分段或翻译；只转写模式仍输出主模型原文。这会增加本地计算与 API 调用，不保证绝对更准确；30 秒以上录音保持单模型。
- 识别语言提供千问 ASR 官方语言参数选项；多语混说请选择自动。
- 模式有智能渲染、翻译、只转写。
- 渲染风格有通用润色、工作邮件、聊天回复、会议笔记、Markdown、编程模式。
- 可以按当前前台应用匹配专属渲染风格，例如 VS Code 使用编程模式、邮件应用使用正式语气。
- 个人词典支持添加、编辑、删除、CSV 导入和导出，并同时提供给 Whisper 和渲染模型。
- 支持选中文字后通过第二个全局快捷键进行语音编辑，结果会替换原选区。
- 支持麦克风选择、输入测试和噪声抑制；停顿或长时间静音不会自动结束，需手动完成或取消录音。
- 支持全局快捷键、系统托盘 / 菜单栏、关闭窗口隐藏，以及 macOS / Windows 开机启动。
- 主窗口隐藏后仍可通过全局快捷键录音；独立的置顶悬浮窗显示实时音量，并提供 `×` 取消与 `✓` 完成。
- 主窗口使用系统原生标题栏与关闭／最小化控件；关闭时隐藏到后台。悬浮窗缩为约 164×40，只绘制圆角胶囊，不再显示方形外框。
- 黑白界面支持浅色和高级灰深色两种模式，并自动保存选择；录音悬浮窗随之切换。
- 历史记录支持搜索、筛选、编辑、复制、重新插入、加入词典、删除和清空，可配置保留时间。
- 每条记录会保存原始转写、可选候选裁决结果、各模型候选文字、最终输出、两阶段完成时间、识别/整理耗时和中英文统计；历史卡片可以展开查看。模型 token 概率不是校准后的准确率。
- 额外保存只存在本机的累计使用次数和输出字数统计；清空历史不会自动抹掉累计统计，历史页面可单独重置统计。
- ASR 返回后会先更新原始转写状态；最终文本完成插入后，字数统计、历史记录和累计统计在下一轮事件循环异步保存，不让本地存储拖慢文本交付。LLM 渲染本身仍是智能口述、翻译和选区编辑得到最终文本所必需的步骤。
- LLM 调用失败时可以自动回退为本地原始转写，避免丢失口述内容。
- Whisper Context 会在首次识别后复用，渲染请求复用长生命周期 HTTP 连接池；失败时只对网络、超时、限流和服务端错误自动重试。
- API Key 使用 macOS Keychain 或 Windows Credential Manager，不写入 config.json、前端 localStorage 或打包资源。
- 支持预置 DeepSeek、智谱 GLM、OpenAI，也支持自定义 Base URL 和 Model。
- 程序图标使用黑白声波 U：15 根细密圆头音频柱，底部平齐、两侧高中央低。创意概念来自图像生成，发布图标由 `scripts/make-wave-icon.swift` 精确绘制，以消除圆角边缘散点。此前的毛笔字标仍保留为辅助品牌资产。

## 本地运行

环境要求：

- Node.js 20 或更高版本
- Rust stable
- Tauri 2 的系统依赖
- 编译 whisper-rs 需要 CMake

安装依赖：

    npm install

启动前端：

    npm run dev

启动桌面应用：

    npm run tauri:dev

构建当前操作系统：

    npm run tauri:build

重新生成图标（macOS）：

    swift scripts/make-wave-icon.swift src-tauri/icons/source-u-words.png
    npx tauri icon src-tauri/icons/source-u-words.png

## 首次使用

### 千问云端：只填写 Token

1. 打开设置 → 语音识别来源，粘贴百炼 API Key / Token，点击“保存并启用”。北京地域接口和识别模型已配置，无需填写 Workspace ID、Base URL 或模型名称。新加坡 Key 先切换地域。
2. 如希望一个 Token 同时完成识别和整理，开启“同一 Token 用于文字整理”。没有旧渲染 Key 时默认勾选；已有渲染 Key 时默认沿用原服务商，不覆盖它。
3. 麦克风和自动插入所需的系统权限仍需用户授权。Token 保存不会测试余额或权限，首次识别才真实调用百炼。
4. 音频上传至所选百炼地域；历史只存在本机，不保存原始音频。敏感录音请选择本地 Whisper。个人词典作为 ASR 上下文；自动语言模式不强制单一语种，支持中英文混说。
5. 单段最多 5 分钟且 Base64 编码后不超过 10 MB；未压缩 16 kHz WAV 可能在约 234 秒达到大小上限，建议每段不超过约 3 分钟。此版是录音结束后提交，不是麦克风实时 WebSocket 识别。
6. Esc / × 取消后丢弃晚到结果，不再整理或插入；当前不会向服务商发出撤销任务，已经发送的请求仍可能被处理和计费。

接口依据：[Qwen-ASR API](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[思考模式](https://help.aliyun.com/en/model-studio/deep-thinking)。使用官方仍支持的通用域名以避免要求用户再填写 Workspace ID；未来可增加业务空间专属域名配置。

### 本地 Whisper

1. 安装后默认已经具备 Whisper Small Q5；打开设置可以查看内置模型，也可以按设备性能下载并切换到 tiny 或 base。
2. 在“麦克风与录音”中选择输入设备并完成测试。
3. 给 macOS 的 U-Words 开启麦克风和辅助功能权限；Windows 需要允许桌面应用使用麦克风。
4. 如果要智能渲染或翻译，选择服务商，填写 Base URL、Model 和 API Key。
5. 在设置中确认“完成后自动插入”和“渲染失败时回退原文”。
6. 在任意输入框按口述快捷键；主窗口可以保持隐藏，录音悬浮窗会显示在屏幕下方，口述完成后点击 `✓` 或再次按快捷键。
7. 需要编辑已有文字时，先在目标应用中选中文本，再按选区编辑快捷键并说出修改指令。

## 选区编辑

选中目标应用里的文字后，按默认的 `CommandOrControl+Shift+E`，U-Words 会先读取选区，再录制语音编辑指令。可以说：

- 把这段话改得正式一点
- 缩短到三句话
- 整理成项目符号
- 翻译成英文
- 修正错别字，但不要改变意思

选区编辑需要配置 LLM API Key；如果没有 API Key，普通口述仍然可以通过只转写模式使用，但不会把编辑指令误当成替换文本。

## OpenAI-compatible 接入

应用调用的是 Chat Completions 兼容接口：

- OpenAI：`https://api.openai.com/v1`
- DeepSeek：`https://api.deepseek.com/v1`
- 智谱：`https://open.bigmodel.cn/api/paas/v4`

Base URL 可以填写到 `/v1`、`/v4` 或 `/api`，应用会自动补全 `/chat/completions`；也可以直接填完整的 `/chat/completions` 地址。

兼容层只依赖标准的 `model`、`messages`、`temperature` 字段和 `choices[0].message.content` 响应。部分供应商若有额外网关要求，可使用自定义 Base URL。

## 数据边界

- 麦克风音频在前端采集后直接送入本机 Rust ASR，不上传音频。
- 原始转写和最终文本保存在本机 localStorage；可设置保留期限，也可以随时清空。
- 累计使用次数和字数保存在本机 localStorage 的独立统计项中，不受历史保留期限影响。
- 默认不保存原始音频。
- 只有智能渲染、翻译和选区编辑会把必要的文字发送给用户选择的模型服务商。
- API Key 只进系统凭据库。
- 个人词典会随转写请求发送给本机 ASR 参数，并随渲染请求发送给模型作为提示词。
- 当前前台应用名称只用于选择应用级渲染风格，不发送给模型以外的服务；如果对应的渲染请求发出，应用名称会作为有限上下文一并发送给所选模型。

## 跨平台构建

本机可以构建 macOS 版本。Windows 安装包需要在 Windows runner 或 Windows 机器上构建，因为 whisper-rs 原生依赖、Tauri bundler 和系统签名环境都与目标平台绑定。

仓库附带 `.github/workflows/build.yml`。推送到 GitHub 后，它会分别在 macOS arm64 和 Windows x64 上运行 npm ci、Rust 构建和 Tauri 打包，并上传 bundle 产物。内置的 Whisper Small Q5 通过 Git LFS 存储；克隆与 CI 构建均需先安装 Git LFS 并拉取模型。正式发布前还应补充代码签名、权限引导和真人验收。

## 悬浮窗与后台使用

- 关闭主窗口只会隐藏它，不会退出后台进程；托盘图标和两个全局快捷键仍然有效。
- 录音时会显示一个约 164×40 的透明置顶窗口，窗口中只有黑白或高级灰描边的胶囊，视觉上是“左侧 `×`／中间实时音量波形／右侧 `✓`”；音量分析约 30 fps 更新，点击 `×` 或按 `Esc` 都会取消当前录音。
- 转写和渲染期间只保留取消按钮；成功状态会显示短暂的 `✓` 后自动隐藏，错误状态会保留几秒供用户关闭。
- 悬浮窗默认不抢目标应用焦点，避免自动粘贴时把结果插回 U-Words；取消只作用于当前尚未插入的录音或处理任务，不会在用户后续输入后盲目发送撤销快捷键。
- 为保留现有用户的 Keychain、设置和历史数据，并尽量延续系统权限识别，升级后仍使用原有 bundle identifier `com.personal.whisperdesk` 与本地存储键；这不影响面向用户显示的 U-Words 名称。未使用固定开发者证书签名的构建仍可能需要重新授权辅助功能。

## 已知边界

- 当前录音使用浏览器 Web Audio 的 PCM 捕获接口，Whisper 输入保持 16 kHz；音量显示通过 AnalyserNode 和独立刷新节奏优化，支持输入设备和降噪，无静音自动结束；后续可以换成 AudioWorklet/cpal 以获得更低延迟。
- 当前实时悬浮窗已经支持录音、处理中、完成和失败的取消 / 确认交互，但 ASR 仍然在录音结束后进行完整识别，暂未做逐字流式预览。
- macOS 的自动启动写入当前用户的 LaunchAgent；Windows 使用当前用户的 Run 启动项，不需要管理员权限。
- macOS 构建使用临时（ad-hoc）签名，尚无固定开发者证书与公证；Windows 也未签名。正式分发前需要配置对应平台证书。
- 由于内置了约 190 MB 的 Whisper Small Q5，安装包会明显大于只带运行时的版本；tiny/base 不会重复打进安装包。
- 透明 macOS 悬浮窗使用 Tauri 的 `macOSPrivateApi`，适合直接分发，但不以 Mac App Store 上架为目标。
