# U-Words

U-Words 是一个个人向、轻量的桌面口述工具。它把本地 Whisper 语音识别、可选的大模型渲染和系统光标插入组合成一条短链路。

它不包含网页搜索、问答、账号体系、云端历史或订阅计费。

## 当前实现（0.5.0）

- Tauri 2 + React + TypeScript，桌面壳体小，核心处理在 Rust 主进程。
- 本地 ASR 使用 whisper.cpp / whisper-rs，支持 tiny、base、small 的 Q5 模型档位。
- 默认使用随应用内置的 Whisper Small Q5（约 181 MiB / 190 MB），不需要首次联网下载；tiny、base 仍可在设置中按需下载和切换。
- 识别方式默认是单模型快速模式；可选“高精度”模式按录音时长运行已安装的 tiny/base/small 模型，保留各模型候选与主模型原文。智能渲染和翻译中的不同候选会交给用户配置的大模型保守裁决，再进行标点、分段或翻译；只转写模式仍输出主模型原文。这会增加本地计算与 API 调用，不保证绝对更准确；30 秒以上录音保持单模型。
- 语言有自动、中文、English。
- 模式有智能渲染、翻译、只转写。
- 渲染风格有通用润色、工作邮件、聊天回复、会议笔记、Markdown、编程模式。
- 可以按当前前台应用匹配专属渲染风格，例如 VS Code 使用编程模式、邮件应用使用正式语气。
- 个人词典支持添加、编辑、删除、CSV 导入和导出，并同时提供给 Whisper 和渲染模型。
- 支持选中文字后通过第二个全局快捷键进行语音编辑，结果会替换原选区。
- 支持麦克风选择、输入测试、噪声抑制、VAD 静音自动结束。
- 支持全局快捷键、系统托盘 / 菜单栏、关闭窗口隐藏，以及 macOS / Windows 开机启动。
- 主窗口隐藏后仍可通过全局快捷键录音；独立的置顶悬浮窗显示实时音量，并提供 `×` 取消与 `✓` 完成。
- 主窗口使用系统原生标题栏与关闭／最小化控件；关闭时隐藏到后台。悬浮窗缩为约 184×46，只绘制圆角胶囊，不再显示方形外框。
- 黑白界面支持浅色和高级灰深色两种模式，并自动保存选择；录音悬浮窗随之切换。
- 历史记录支持搜索、筛选、编辑、复制、重新插入、加入词典、删除和清空，可配置保留时间。
- 每条记录会保存原始转写、可选候选裁决结果、各模型候选文字、最终输出、两阶段完成时间、识别/整理耗时和中英文统计；历史卡片可以展开查看。模型 token 概率不是校准后的准确率。
- 额外保存只存在本机的累计使用次数和输出字数统计；清空历史不会自动抹掉累计统计，历史页面可单独重置统计。
- ASR 返回后会先更新原始转写状态；最终文本完成插入后，字数统计、历史记录和累计统计在下一轮事件循环异步保存，不让本地存储拖慢文本交付。LLM 渲染本身仍是智能口述、翻译和选区编辑得到最终文本所必需的步骤。
- LLM 调用失败时可以自动回退为本地原始转写，避免丢失口述内容。
- Whisper Context 会在首次识别后复用，渲染请求复用长生命周期 HTTP 连接池；失败时只对网络、超时、限流和服务端错误自动重试。
- API Key 使用 macOS Keychain 或 Windows Credential Manager，不写入 config.json、前端 localStorage 或打包资源。
- 支持预置 DeepSeek、智谱 GLM、OpenAI，也支持自定义 Base URL 和 Model。
- 程序图标使用黑白声波 U：15 根细密圆头音频柱，底部平齐、两侧高中央低。创意概念来自图像生成，发布图标由 `scripts/make-wave-icon.swift` 精确绘制，以消除圆角边缘散点。此前的毛笔字标仍保留为辅助品牌资产。

## 本地运行

环境要求：

- Node.js 20 或更高版本
- Rust stable
- Tauri 2 的系统依赖
- 编译 whisper-rs 需要 CMake

安装依赖：

    npm install

启动前端：

    npm run dev

启动桌面应用：

    npm run tauri:dev

构建当前操作系统：

    npm run tauri:build

重新生成图标（macOS）：

    swift scripts/make-wave-icon.swift src-tauri/icons/source-u-words.png
    npx tauri icon src-tauri/icons/source-u-words.png

## 首次使用

1. 安装后默认已经具备 Whisper Small Q5；打开设置可以查看内置模型，也可以按设备性能下载并切换到 tiny 或 base。
2. 在“麦克风与录音”中选择输入设备并完成测试。
3. 给 macOS 的 U-Words 开启麦克风和辅助功能权限；Windows 需要允许桌面应用使用麦克风。
4. 如果要智能渲染或翻译，选择服务商，填写 Base URL、Model 和 API Key。
5. 在设置中确认“完成后自动插入”和“渲染失败时回退原文”。
6. 在任意输入框按口述快捷键；主窗口可以保持隐藏，录音悬浮窗会显示在屏幕下方，口述完成后点击 `✓` 或再次按快捷键。
7. 需要编辑已有文字时，先在目标应用中选中文本，再按选区编辑快捷键并说出修改指令。

## 选区编辑

选中目标应用里的文字后，按默认的 `CommandOrControl+Shift+E`，U-Words 会先读取选区，再录制语音编辑指令。可以说：

- 把这段话改得正式一点
- 缩短到三句话
- 整理成项目符号
- 翻译成英文
- 修正错别字，但不要改变意思

选区编辑需要配置 LLM API Key；如果没有 API Key，普通口述仍然可以通过只转写模式使用，但不会把编辑指令误当成替换文本。

## OpenAI-compatible 接入

应用调用的是 Chat Completions 兼容接口：

- OpenAI：`https://api.openai.com/v1`
- DeepSeek：`https://api.deepseek.com/v1`
- 智谱：`https://open.bigmodel.cn/api/paas/v4`

Base URL 可以填写到 `/v1`、`/v4` 或 `/api`，应用会自动补全 `/chat/completions`；也可以直接填完整的 `/chat/completions` 地址。

兼容层只依赖标准的 `model`、`messages`、`temperature` 字段和 `choices[0].message.content` 响应。部分供应商若有额外网关要求，可使用自定义 Base URL。

## 数据边界

- 麦克风音频在前端采集后直接送入本机 Rust ASR，不上传音频。
- 原始转写和最终文本保存在本机 localStorage；可设置保留期限，也可以随时清空。
- 累计使用次数和字数保存在本机 localStorage 的独立统计项中，不受历史保留期限影响。
- 默认不保存原始音频。
- 只有智能渲染、翻译和选区编辑会把必要的文字发送给用户选择的模型服务商。
- API Key 只进系统凭据库。
- 个人词典会随转写请求发送给本机 ASR 参数，并随渲染请求发送给模型作为提示词。
- 当前前台应用名称只用于选择应用级渲染风格，不发送给模型以外的服务；如果对应的渲染请求发出，应用名称会作为有限上下文一并发送给所选模型。

## 跨平台构建

本机可以构建 macOS 版本。Windows 安装包需要在 Windows runner 或 Windows 机器上构建，因为 whisper-rs 原生依赖、Tauri bundler 和系统签名环境都与目标平台绑定。

仓库附带 `.github/workflows/build.yml`。推送到 GitHub 后，它会分别在 macOS arm64 和 Windows x64 上运行 npm ci、Rust 构建和 Tauri 打包，并上传 bundle 产物。内置的 Whisper Small Q5 通过 Git LFS 存储；克隆与 CI 构建均需先安装 Git LFS 并拉取模型。正式发布前还应补充代码签名、权限引导和真人验收。

## 悬浮窗与后台使用

- 关闭主窗口只会隐藏它，不会退出后台进程；托盘图标和两个全局快捷键仍然有效。
- 录音时会显示一个约 184×46 的透明置顶窗口，窗口中只有黑白或高级灰描边的胶囊，视觉上是“左侧 `×`／中间实时音量波形／右侧 `✓`”；音量分析约 30 fps 更新，点击 `×` 或按 `Esc` 都会取消当前录音。
- 转写和渲染期间只保留取消按钮；成功状态会显示短暂的 `✓` 后自动隐藏，错误状态会保留几秒供用户关闭。
- 悬浮窗默认不抢目标应用焦点，避免自动粘贴时把结果插回 U-Words；取消只作用于当前尚未插入的录音或处理任务，不会在用户后续输入后盲目发送撤销快捷键。
- 为保留现有用户的 Keychain、设置和历史数据，并尽量延续系统权限识别，升级后仍使用原有 bundle identifier `com.personal.whisperdesk` 与本地存储键；这不影响面向用户显示的 U-Words 名称。未使用固定开发者证书签名的构建仍可能需要重新授权辅助功能。

## 已知边界

- 当前录音使用浏览器 Web Audio 的 PCM 捕获接口，Whisper 输入保持 16 kHz；音量显示通过 AnalyserNode 和独立刷新节奏优化，已经支持输入设备、降噪和简单 VAD；后续可以换成 AudioWorklet/cpal 以获得更低延迟。
- 当前实时悬浮窗已经支持录音、处理中、完成和失败的取消 / 确认交互，但 ASR 仍然在录音结束后进行完整识别，暂未做逐字流式预览。
- macOS 的自动启动写入当前用户的 LaunchAgent；Windows 使用当前用户的 Run 启动项，不需要管理员权限。
- macOS 构建使用临时（ad-hoc）签名，尚无固定开发者证书与公证；Windows 也未签名。正式分发前需要配置对应平台证书。
- 由于内置了约 190 MB 的 Whisper Small Q5，安装包会明显大于只带运行时的版本；tiny/base 不会重复打进安装包。
- 透明 macOS 悬浮窗使用 Tauri 的 `macOSPrivateApi`，适合直接分发，但不以 Mac App Store 上架为目标。
